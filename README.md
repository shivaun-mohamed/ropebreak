# ROPEBREAK

## Description

ROPEBREAK is a wrestling simulator using wrestler stats and randomness to determine outcomes. I had the idea for it when looking at beginner programming projects as it stemmed from a damage calculator to a match engine and simulator. This is my first personal project!
