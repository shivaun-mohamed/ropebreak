# ROPEBREAK

## Description

ROPEBREAK is a wrestling simulator using wrestler stats and randomness to determine outcomes. I had the idea for it when looking at beginner programming projects as it stemmed from a damage calculator to a match engine and simulator. This is my first personal project!

### Features:

### Planned Features:
- Choice of wrestlers
- Create a wrestler
- Choice of match type
- Move sequencing in commentary to provide better match flow
- Commentary to reflect different match types (including weapons, number of participants, etc)
- Program memory (i.e., current champions, previous champions, match records, in royal rumbles, we should be able to commentate fast and remember multiple things at once, etc)
- Save and Load functions
